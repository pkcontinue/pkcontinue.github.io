Large Language Model Team

Worked on Deep Search reward modeling, function-calling supervision, and evaluation systems, connecting online failure analysis to model post-training.

Deep Search reward modeling · Core contributor

Scaled training-data production with evidence verification, hallucination attribution, and scoring rationales. Built 20,000 verifiable SFT examples for a Qwen3-32B reward model, followed by GRPO training. The GRM reached 78% accuracy on a 600-case benchmark; rubric-based scoring reached 80% agreement with human labels on 150 questions. Reward signals supported RL experiments with a 20-point GSB improvement over the base model.

Data flywheel · Core contributor

Built generation- and retrieval-side failure mining workflows over large-scale online queries. Multi-round agents identified intent mismatch, factual errors, outdated information, incomplete answers, and logical inconsistency. Retrieval analysis distinguished missing evidence from conservative refusals, producing high-confidence cases for RAG and SFT/RLHF training.

Plugin error attribution & model iteration · Project owner

Designed a four-stage diagnostic workflow covering call necessity, tool routing, argument generation, and returned-document quality. End-to-end scoring reached 89% human agreement, and attribution agreement improved from 50% to 84%. Built rubric generation and verification workflows, reaching 88% and 95%+ agreement respectively. Targeted training improved the proportion of plugin documents scoring at least 1 from 81% to 86%, with a 10-point gain for map plugins.

Function-calling supervision & evaluation · Project owner

Led automated label/score/reason production from query intent through tool selection, argument generation, execution, and result evaluation. Designed per-plugin evaluation sets with 100 positive and 50 negative examples. Across 300 queries covering 92 plugins, tool-selection labels reached 92%+ exact match at 62% coverage, and argument accuracy reached 91.41% at 89% coverage. The workflow reduced manual annotation cost by 58% for the referenced evaluation sets.
